# 📚 PaperSage

Agentic RAG over ML research papers — grounded, cited answers with hybrid retrieval,
a fine-tuned cross-encoder reranker, and an honest "I don't know" when the evidence
isn't there.

Source code: https://github.com/agarwalyutika/agentic-rag-ml-papers

> Note: this is a free hosted demo. Accounts/chats are ephemeral (reset on restart),
> and it shares a single API quota, so heavy traffic may briefly rate-limit.
